# Contributing

Bug reports are welcome. Open a GitHub issue describing what happened and what you expected.

Story and feature pull requests are welcome too.

## Media

Any pull request that adds or changes media must meet all three of these requirements:

1. **Provenance.** Record the new or changed assets in the repository's existing provenance format under `shared/edition/source-media/`, matching the records already kept for the same kind of asset.
2. **Provider.** Generate the media with a US-headquartered provider billed directly. The Mureka soundtrack exception does not apply to contributions.
3. **Grant.** Contribute the media under the repository's [media terms](MEDIA-TERMS.md): all rights reserved, view-only, and not for machine-learning training.
