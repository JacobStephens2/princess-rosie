# License code under MIT and keep media view-only

The public repository carries two kinds of work: source, documentation, and tooling that anyone may reuse, and generated art, cutouts, soundtrack, and sound effects that portray the owner's family as storybook characters. The code and documentation are licensed under MIT so a fork can become another child's game. The media under `shared/`, `apps/web/public/assets`, and the built site stays all rights reserved and view-only: a fork must generate its own art and music. Two facts settled this rather than a single permissive license. The media is Rosie and Zélie, and should not travel. The Mureka API agreement also forbids using generated output for machine-learning training, which a plain MIT grant over the audio would contradict. Contributed media is accepted only under the same view-only terms, so the statement stays true after a pull request merges. The vendored skills from mattpocock/skills are MIT and keep their copyright notice.
