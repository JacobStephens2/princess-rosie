# Preserve a one-button shared-reading journey

> The Path Choice and Journey History portions of this decision are superseded by [ADR-0009](./0009-prioritize-flight-control-over-mvp-path-choices.md), and the three-bump Cloud Rest portion by [ADR-0013](./0013-keep-one-game-mode-and-answer-low-flight-with-a-floor.md). The remaining one-button, no-failure journey decision stays active.

The Production Editions will remain an approachable, no-failure journey for a pre-reader and Grown-up Helper rather than expanding into a conventional platform game: Stella moves forward automatically, one hold-or-release action controls flight, and an eight-to-twelve-minute playthrough alternates active play with self-paced Storybook Moments that have no prerecorded narration. Three equally safe Path Choices add meaningful agency and replay variation, while a three-bump Cloud Rest preserves progress and quietly increases assistance without exposing difficulty settings.

The experience uses a layered 2D picture-book presentation inside a 16:9 Storybook Stage, rebuilt animation-ready artwork, and a responsive Fairytale Soundscape. This deliberately favors shared reading, immediate comprehension, replayable delight, and authored sensory polish over additional controls, failure states, scoring, completion pressure, or simulation depth.
