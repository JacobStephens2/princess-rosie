# Revise the existing Phaser Edition with shared presentation

Revise the existing browser application and `rosi.stephens.page` deployment in place as the Phaser Edition, rather than preserving an unchanged Original Edition or creating a second Phaser application. This deliberately replaces GitHub issue #15's earlier Phaser boundary: owner-accepted source media remain canonical under `shared/edition/`, a build step prepares optimized browser derivatives, and Phaser presents each place through a full Storybook Stage illustration with restrained engine-native motion while preserving its journey rules and independently authored interaction geometry.

The Rose Garden experiment on `prototype/phaser-rose-garden-visual` at `962c9b7` passed owner before-and-after review and focused-desktop play on 2026-08-23. It validated the core composition and existing interaction geometry while sharpening the production constraints below.

## Consequences

- The approved Princess Rosie-and-Stella cutout replaces the primitive character drawing and receives whole-cutout motion; purpose-made animation layers may be considered later if playtesting finds it too static.
- Place Illustrations change while Birthday Star Moments cover the Storybook Stage instead of being stretched into scrolling panoramas. Production must prevent the neighbouring world-space scenery from overdrawing the active illustration during the transition.
- Place Illustrations exclude gameplay-significant objects that Phaser presents separately. The Rose Garden painting's duplicate Birthday Star competed with the gameplay star in the prototype, so an approved star-free Place Illustration is release-blocking rather than optional cleanup.
- Procedural interactive elements remain, but obstacles and the Family Guest must be visually retuned to belong against the painted scenery; primitive scenery disappears only where an accepted Place Illustration replaces it.
- The Flight Presentation may publish one accepted place at a time after desktop visual signoff because the existing deployment has no outside audience; unapproved candidate media never becomes canonical merely because an engine already displays it.
- The completed branch-only visual prototype used the real Phaser journey from flight launch through Rosalia's Rose Garden and its first Birthday Star Moment before production media-pipeline work began.
- After prototype signoff, rename `apps/phaser-original` and its package identifiers to `apps/phaser`; the public URL remains unchanged.
- The first production release is one coherent Rose Garden tracer: the rename, prepared-media pipeline, approved clean Place Illustration, Princess Rosie-and-Stella cutout, preserved interactions, acceptance coverage, and deployment ship together.
- This presentation revision does not port the Godot Edition's place-specific vignettes. Any move from Phaser's existing journey mechanics toward cross-edition experiential parity is a separate initiative.
- Prototype signoff compared the Phaser Edition before and after, with the Godot Edition serving only as a visual reference. The owner found it clearly prettier and confirmed clean and appropriately scaled character presentation, restrained motion, readable interactive elements, fair-feeling controls and Playful Bumps, and an unstretched, seamless, smooth 1280×720 Storybook Stage.
